The core, no framework

Mounted with createEditor(host, { plugins, theme }). Click a link for the balloon, drag across cells to merge them, use the chain menu for internal links.

The React binding, as Sulu Admin uses it

      

      
A controlled component with value, onChange and onBlur, the Sulu theme, CKEditor-compatible markup through suluPreset(), and the host's own dialog for internal links.

      

    


    

      

        
Symfony UX

        
composer require primavista/ux-bundle, then PrimavistaType in a form. The Stimulus controller is one file served by AssetMapper, no build step.

      

      

        
Sulu

        
A reference adapter replaces CKEditor 5 in Sulu Admin, verified against Sulu's Jest, Flow, ESLint and webpack build and clicked through in a running admin. Internal links, validation states and enter_mode included.

Plugins

        
Bold, lists, tables and links are plugins. A plugin is nodes, toolbar items and a register hook. Hosts add their own through the same interface.
