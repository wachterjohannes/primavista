Primavista

Primavista is a WYSIWYG editor built as a framework-agnostic JavaScript core with first-class bindings for Symfony UX and React. What editors see while writing is exactly what ends up on the page, with no hidden formatting surprises and no mental translation between editing and publishing. The same editor can drop into a Twig template via Symfony UX or into a React application, so PHP and JavaScript projects can share one consistent editing experience.

Packages: @primavista/core, @primavista/react, and a Symfony UX bundle on Packagist.
